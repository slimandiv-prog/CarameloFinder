# 🐾 CarameloFinder
O CarameloFinder é uma aplicação web desenvolvida como projeto final do curso da TOTI. O objetivo é ajudar pessoas a divulgar animais perdidos ou encontrados, facilitando a localização dos animais e o reencontro com seus responsáveis.

🎯 Objetivo

Criar uma plataforma simples, intuitiva e responsiva para cadastrar, consultar e gerenciar relatos de animais perdidos e encontrados.

✨ Funcionalidades

- Visualizar os relatos publicados.
- Cadastrar animais perdidos ou encontrados.
- Consultar os detalhes de cada relato.
- Buscar relatos por nome do animal ou localização.
- Filtrar relatos por tipo.
- Editar e excluir relatos.
- Atualizar o status de um relato para indicar que o animal foi localizado.

🛠️ Tecnologias

HTML5 | CSS3 | JavaScript | React | Node.js | API REST | SQL

## User Stories

| Como | Eu quero | Para que |
|---|---|---|
| Como visitante | Acessar a página inicial do CarameloFinder | Entender a finalidade da plataforma e encontrar rapidamente os animais cadastrados |
| Como pessoa que perdeu ou encontrou um animal | Cadastrar um relato com as informações do animal | Divulgar o ocorrido e facilitar sua localização |
| Como visitante | Visualizar os relatos de animais perdidos e encontrados | Identificar animais que correspondam às informações que procuro |
| Como visitante | Filtrar os relatos entre animais perdidos e encontrados | Visualizar somente as ocorrências relevantes para minha busca |
| Como visitante | Pesquisar relatos pelo nome do animal ou pela localização | Encontrar ocorrências relacionadas à minha busca |
| Como visitante | Consultar os detalhes de um relato | Conhecer melhor o animal e entrar em contato com o responsável |
| Como responsável por um relato | Editar as informações do animal | Corrigir dados ou informar mudanças na ocorrência |
| Como responsável por um relato | Excluir um registro | Remover uma publicação que não precisa mais ficar disponível |
| Como responsável por um relato de animal perdido | Marcar o caso como resolvido | Informar que o animal foi localizado e evitar buscas desnecessárias |
