User Story — CarameloFinder

**Visualizar a página inicial

Como visitante, quero acessar uma página inicial com informações sobre o CarameloFinder e os relatos publicados, para entender a finalidade da plataforma e encontrar rapidamente os animais cadastrados.


**Cadastrar um relato de animal perdido ou encontrado

Como pessoa que perdeu ou encontrou um animal, quero preencher um formulário com as informações do animal, para divulgar o ocorrido e facilitar sua localização.


**Listar os relatos cadastrados

Como visitante, quero visualizar os relatos de animais perdidos e encontrados, para identificar animais que correspondam às informações que procuro.


**Filtrar relatos por tipo

Como visitante, quero filtrar os relatos entre animais perdidos e encontrados, para visualizar somente as ocorrências relevantes para minha busca.


**Buscar relatos

Como visitante, quero pesquisar relatos pelo nome do animal ou pela localização, para encontrar ocorrências relacionadas à minha busca.


**Visualizar os detalhes de um relato

Como visitante, quero abrir um relato para consultar suas informações completas, para conhecer melhor o animal e entrar em contato com o responsável.


**Editar um relato

Como responsável por um relato cadastrado,quero atualizar as informações do animal, para corrigir dados ou informar mudanças na ocorrência.


**Excluir um relato

Como responsável por um relato, quero excluir um registro, para remover uma publicação que não precisa mais ficar disponível.


**Atualizar o status do relato

Como responsável por um relato de animal perdido, quero marcar o caso como resolvido, para informar que o animal foi localizado e evitar buscas desnecessárias.
